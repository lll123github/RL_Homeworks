## Usage Example:

```matlab
% Create the network
net = CustomNetwork();

% Create an 8D input vector (example values)
input = [1; 0.5; -0.3; 0.2; -0.7; 0.4; -0.1; 0.6];

% Perform inference
output = net.forward(input);
disp(['Network output: ', num2str(output)]);
```

## Notes:

1. The implementation follows the Python network architecture with three fully connected layers.
2. Each layer is followed by a ReLU activation function (max(0, x)) as in the Python code.
3. The final output is computed as `fc3_output * action_weight + bias`.
4. The weights are transposed compared to the Python version because MATLAB uses column-major order while Python (with NumPy) uses row-major order.
5. The input should be an 8×1 column vector for correct matrix multiplication.

If you need to process multiple inputs at once (batch processing), you would need to modify the implementation to handle matrices where each column is an input vector.
